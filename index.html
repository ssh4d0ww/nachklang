Nachklang

Your Spotify remote in the Liner look. The music keeps playing in Spotify, you control it from here.

Where do I get it?
  1. Create an app at developer.spotify.com/dashboard (tick Web API).
  2. Add exactly this address as a Redirect URI:
  3. Paste the app's Client ID here.

This is a preview, so only the demo works here. Host the app yourself to use your own music (see README).

Controlling playback requires Spotify Premium. Nothing is stored except your login in this browser.

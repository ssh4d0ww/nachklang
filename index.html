Nachklang

Deine Spotify-Fernbedienung im Liner-Look. Die Musik läuft weiter in Spotify, hier steuerst du sie.

Woher bekomme ich die?
  1. Auf developer.spotify.com/dashboard eine App anlegen (Web API anhaken).
  2. Als Redirect URI genau diese Adresse eintragen:
  3. Die Client ID der App hier einfügen.

Das ist die Vorschau: Hier läuft nur die Demo. Für deine echte Musik die App selbst hosten (siehe README).

Steuern braucht Spotify Premium. Es werden keine Daten gespeichert außer dem Login in diesem Browser.
